# 흑선행 黑線行 — 설치 가이드

다크 판타지 무협 탐색 웹게임. 코딩을 몰라도 아래 순서대로 따라 하면 **무료로** 인터넷에 올릴 수 있습니다.

- 게임 화면은 **GitHub Pages**(무료)에 올립니다.
- 로그인, 저장, 전공록, 교환, 공동 임무는 **Supabase**(무료)를 씁니다.
- Supabase를 연결하기 전에도 **체험 모드**로 게임이 돌아가는지 먼저 확인할 수 있습니다.

---

## 0. 파일 구성

| 파일 | 하는 일 | 직접 고칠 일 |
|---|---|---|
| `index.html` | 화면 뼈대 | 거의 없음 |
| `style.css` | 색과 모양 (다크 무협 테마) | 색을 바꾸고 싶을 때 맨 위 `:root` 부분만 |
| `game.js` | 게임 동작 | 없음 |
| `data.js` | **맵, 재료, 몬스터, 요리/제작법, 이벤트 문구** | 커뮤 설정에 맞게 자유롭게 |
| `config.js` | Supabase 연결 주소와 키 | 4단계에서 딱 한 번 |
| `schema.sql` | Supabase 데이터베이스 설정 | 3단계에서 복사해서 실행만 |
| `admin.html`, `admin.js` | 운영 페이지 (우편으로 물품 지급) | 묶음 구성만 `admin.js`에서 |
| `hanji.png` | 한지 결 그림 | 바꾸고 싶을 때만 |

## 1단계. GitHub에 올리기

1. [github.com](https://github.com) 에 가입하고 로그인합니다.
2. 오른쪽 위 **＋** 버튼 → **New repository** 를 누릅니다.
3. 설정:
   - **Repository name**: 영문으로 아무 이름 (예: `heukseon`). 이 이름이 주소에 들어갑니다.
   - **Public** 선택 (무료 GitHub Pages는 공개 저장소에서만 됩니다)
   - 나머지는 건드리지 않고 **Create repository**
4. 새로 생긴 저장소 화면에서 **uploading an existing file** 이라는 파란 글씨를 누릅니다.
   (안 보이면 **Add file → Upload files**)
5. 압축을 푼 폴더 **안의 파일들**(index.html, style.css, game.js, data.js, config.js, schema.sql, README.md)을 전부 선택해서 화면에 끌어다 놓습니다.
   - ⚠️ 폴더째로 올리지 말고 **파일들만** 올려야 합니다. `index.html`이 저장소 맨 바깥에 있어야 합니다.
6. 아래 **Commit changes** 버튼을 누릅니다.

## 2단계. 인터넷 주소 만들기 (GitHub Pages)

1. 저장소 화면 위쪽 **Settings** → 왼쪽 메뉴 **Pages**
2. **Build and deployment** 의 **Source** 를 `Deploy from a branch` 로 두고,
   **Branch** 를 `main` / `/ (root)` 로 고른 뒤 **Save**
3. 1~2분 기다린 뒤 새로고침하면 위쪽에 주소가 나옵니다.
   `https://내아이디.github.io/저장소이름/`
4. 그 주소로 들어가서 **체험 모드로 들어가기** 를 눌러 게임이 돌아가는지 확인합니다.
   (이 단계에선 로그인 칸에 "Supabase 미연결" 문구가 뜨는 게 정상입니다)

## 3단계. Supabase 준비

1. [supabase.com](https://supabase.com) 에 가입합니다. (GitHub 계정으로 가입하면 편합니다)
2. **New project** 를 누르고:
   - **Name**: 아무거나 (예: heukseon)
   - **Database Password**: 아무거나 길게. 따로 적어두기만 하면 됩니다 (게임에는 안 씁니다)
   - **Region**: `Northeast Asia (Seoul)` 이 있으면 그것을, 없으면 `Tokyo`
   - **Create new project** → 1~2분 기다립니다
3. **표 만들기**: 왼쪽 메뉴 **SQL Editor** → 새 쿼리 화면에 `schema.sql` 파일 내용을 **전부 복사해서 붙여넣고** → 오른쪽 아래 **Run**
   - 여러 번 실행해도 안전합니다. 기존 기록은 지워지지 않습니다.
   - `Success. No rows returned` 가 나오면 성공입니다.
4. **이메일 확인 끄기** (아이디 로그인을 쓰기 위해 꼭 필요)
   - 왼쪽 메뉴 **Authentication** → **Sign In / Providers**(또는 Providers) → **Email**
   - **Confirm email** 을 **끄고** 저장합니다.
   - 이걸 안 끄면 가입할 때 "이메일 확인이 켜져 있습니다" 오류가 납니다.

## 4단계. 게임과 Supabase 연결하기

1. Supabase 왼쪽 아래 **Project Settings**(톱니바퀴) → **Data API** 또는 **API** 메뉴에서
   **Project URL** 을 복사합니다. (`https://abcdxyz.supabase.co` 같은 모양)
2. 같은 곳의 **API Keys** 메뉴에서 **publishable** 키(`sb_publishable_...`)를 복사합니다.
   예전 화면이라면 **anon public** 키를 복사하면 됩니다.
   - ⚠️ **secret** 키나 **service_role** 키는 절대 넣지 마세요. 그건 관리자 열쇠입니다.
   - publishable / anon 키는 웹페이지에 공개되어도 괜찮도록 만들어진 키입니다. 3단계의 보안 규칙이 데이터를 지켜줍니다.
3. GitHub 저장소로 돌아가서 `config.js` 를 누르고 → 오른쪽 위 **연필 아이콘(Edit)**
4. 따옴표 안에 붙여넣습니다:
   ```js
   SUPABASE_URL: "https://abcdxyz.supabase.co",
   SUPABASE_KEY: "sb_publishable_어쩌고저쩌고",
   ```
5. 오른쪽 위 **Commit changes** → 다시 **Commit changes**
6. 1~2분 뒤 게임 주소를 **강력 새로고침**(PC: `Ctrl + Shift + R`, 맥: `Cmd + Shift + R`) 합니다.

## 5단계. 확인하기

1. **입적** 탭 → 아이디, 비밀번호, 캐릭터 이름 입력 → **입적하기**
2. 게임 화면이 뜨면 성공. Supabase의 **Table Editor → players** 에 내 캐릭터가 한 줄 생겨 있습니다.
3. **교환 시험**: 다른 브라우저(또는 시크릿 창)에서 다른 아이디로 가입 → 한쪽에서 **교환** 탭으로 상대에게 약초 하나를 보내기
   - 1분 안에 상대 화면에 "꾸러미가 도착했다"가 뜨면 성공입니다.

## 운영 페이지 (admin.html) — 러너에게 물품 지급

게임 주소 뒤에 `/admin.html`을 붙이면 운영 페이지가 열립니다. (예: `https://withwindcloud.site/admin.html`)
GitHub Pages는 PHP를 실행할 수 없어서 `admin.php`가 아닌 `admin.html`로 만들었습니다.
권한은 Supabase가 확인하므로, 주소를 아는 사람이 들어와도 **운영진으로 등록된 계정이 아니면 아무것도 보낼 수 없습니다.**

### 관리자 등록 (처음 한 번)
1. 운영진도 게임에서 평소처럼 **입적(가입)** 합니다.
2. Supabase → **SQL Editor**에서 아래를 실행합니다. `운영진아이디`를 실제 아이디로 바꾸세요.
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = '운영진아이디@heukseon.game'
   on conflict do nothing;
   ```
   - `config.js`의 `ID_EMAIL_DOMAIN`을 바꿨다면 `@heukseon.game` 부분도 그 값으로 바꿉니다.
   - 운영진이 여러 명이면 아이디마다 한 번씩 실행합니다.
3. 운영진에서 빼려면:
   ```sql
   delete from public.admins where user_id = (select id from auth.users where email = '운영진아이디@heukseon.game');
   ```

### 쓰는 법
1. `admin.html`에서 운영진 아이디로 들어갑니다.
2. **받는 이**를 고릅니다. 이름이나 소속으로 찾을 수 있고, **모두 고르기**로 전원에게 보낼 수 있습니다.
3. **보낼 물품**을 정합니다. `기혈 회복`, `행동력 회복`, `회복 꾸러미`, `희귀 재료` 버튼으로 묶음을 한 번에 채울 수 있고, 줄을 더해 아무 물품이나 넣을 수 있습니다.
4. 제목과 내용을 적고 **우편 보내기**.
5. 러너는 게임 상단의 **우편 아이콘(✉)** 에 붉은 숫자가 뜨고, 눌러서 **받기**를 하면 행낭에 들어갑니다. 접속 중이면 1분 안에 숫자가 뜹니다.
6. 아래 **아직 받지 않은 우편** 목록에서 잘못 보낸 우편을 **회수**할 수 있습니다.

묶음 버튼의 구성은 `admin.js` 맨 위 `PRESETS`에서 바꿀 수 있습니다.

## 지도 · 관문 해금 (2주 원정 구조)

- 임시 기지는 **맨 왼쪽 아래**, 흑선탑은 **오른쪽 위 끝**입니다.
- 지도는 **흑수 급류(川)** 와 **단애 절벽(崖)** 4겹으로 나뉘어 있고, 그 사이 관문을 열어야 다음 구역으로 갈 수 있습니다.

| 단계 | 막는 것 | 관문 (둘 중 하나만 열어도 통과) |
|---|---|---|
| 1단계 | 흑수 급류 | 검은나루 외나무다리 / 버드나무 여울목 — 다리 놓기 |
| 2단계 | 단애 절벽 | 매바위 벼랑 / 칡넝쿨 절벽 — 경공 |
| 3단계 | 흑수 급류 | 흑수 돌다리 터 / 옛 관문 나루 — 다리 놓기 |
| 4단계 | 단애 절벽 | 단애 잔도 끝 / 흑선채 망루 절벽 — 경공 → 탑이 있는 구역 |

- 닫힌 관문은 渡(다리 자리)·壁(절벽)으로 보이고, 부딪히면 행동력을 쓰지 않고 막힙니다.
- **운영 페이지 → 맵 해금** 탭에서 「다리 놓기」·「길 열기」를 누르면, 참가자 화면에 1분 안에 「◈ 소식」이 뜨고 橋·躍으로 바뀌어 지나갈 수 있습니다. 「다시 막기」도 됩니다.
- 2주 기준 예시: 3일째 1단계, 6일째 2단계, 9일째 3단계, 12일째 4단계를 열면 마지막 이틀에 탑을 공략하게 됩니다.
- 관문 이름·문구는 `data.js`의 `GATES`에서 바꿀 수 있습니다.

## 주간 의뢰 · 공동 임무 (운영 페이지에서 등록)

**운영 페이지 → 주간 의뢰 · 공동 임무** 탭에서 등록합니다.

- **주간 의뢰**: 각자 채우는 개인 목표. 목표를 채운 사람이 보상을 받습니다.
- **공동 임무**: 모두의 기여를 합산. 합계가 목표에 닿으면 **한 번이라도 기여한 사람**이 보상을 받습니다.
- 종류: 적 처치(특정 적 고르기 가능) · 토벌 승리 · 지형 탐색(특정 지형 고르기 가능) · 새 땅 밝히기 · 재료 납품 · 요리 · 장비 벼리기
- 기간(시작·끝)과 보상(공적 + 물품)을 정합니다. 「지금 끝내기」, 「삭제」도 됩니다.
- 참가자는 **임무 탭**의 「주간 의뢰」, 「공동 임무」 칸에서 진행도를 보고 보상을 받습니다. 납품형은 임시 기지에서 납품 버튼을 누릅니다.

## 게임 규칙 요약

| 행동 | 행동력 | 내용 |
|---|---|---|
| 이동 | 1 | 상하좌우 한 칸. 처음 가는 칸은 안개가 걷힘. 위험한 곳은 이동 중 매복 |
| 탐색 | 1 | 지형별 재료 1~3개 + 낮은 확률로 사건(아이템, 비전 레시피, 함정, 매복) |
| 토벌 | 2 | 자동 전투. 이기면 재료, 공적, 수련(경험치) |
| 휴식 | 0 | 임시 기지(營)와 버려진 야영지(幕)에서. 기혈 전부 회복 |
| 요리/제작 | 0 | 임시 기지에서만. 재료를 소모해 요리(회복+다음 토벌 강화)나 장비 제작 |

- 지도는 **21 × 21칸**이고, 화면에는 내 주변 5 × 5칸만 보입니다. 걸어가면 지도가 따라 움직입니다.
  아래 **전도(全圖)** 에서 지금까지 밝힌 땅 전체를 볼 수 있습니다.
- 기지는 맨 왼쪽 아래, 흑선탑은 오른쪽 위 끝입니다. 탑의 자리는 처음부터 전도에 붉은 점으로 표시됩니다(소문).
- 행동력은 하루 50, **한국 시간 자정**에 다시 찹니다.
- **행동력 회복 요리**: 귀한 재료 **운무초**(늪·잔도·사당에서 아주 드물게, 강시·백부장이 가끔 떨굼)로 만듭니다.
  - 운무차: 운무초 1 + 마른 약초 2 + 들꿀 1 → 행동력 +8
  - 회천단: 운무초 3 + 혈영지 1 + 들꿀 2 → 행동력 +20, 기혈 +30
  - 하루 최대치(50)를 넘겨서 채울 수는 없고, 행동력이 가득할 땐 먹을 수 없습니다.
- 비전 레시피 3종은 폐촌, 독무 늪, 무너진 사당을 **탐색하다가 사건으로** 얻습니다.
- 흑선탑 수문장은 **혼자서 잡을 수 있지만** 경지 10성 이상에 흑철 장비와 요리 효과를 갖춰야 겨우 이길 만한 세기입니다.
- 토벌에서 지면 임시 기지로 후송되고 기혈이 20%만 남습니다.

### 일일 임무 (임무 탭)
- **개인 임무**: 매일 자정에 3개가 새로 붙습니다(사람마다 다름). 토벌, 특정 적 처치, 탐색, 새 땅 밝히기, 재료 납품, 요리, 제작 중에서 뽑힙니다.
  - 끝내면 임무 탭에서 **보상 받기**. 3개를 모두 받으면 추가 보상이 있습니다.
  - 납품 임무는 임시 기지에서 **납품** 버튼을 누릅니다.
- **주간 의뢰 · 공동 임무**: 운영진이 운영 페이지에서 등록합니다(위 설명 참고).
- 받을 보상이 있으면 임무 탭에 붉은 점이 뜹니다.

### 교환 (교환 탭)
- 행낭의 물품을 다른 참가자에게 **꾸러미**로 보냅니다. 한마디(60자)를 함께 적을 수 있습니다.
- 받는 사람은 접속 중이면 1분 안에, 아니면 다음에 접속할 때 받습니다. 보낸 물품은 되돌릴 수 없습니다.

### 내 정보 (프로필)
- 상단 왼쪽의 두상과 이름(또는 사람 모양 버튼)을 누르면 **내 정보** 창이 열립니다.
- **편집** 탭에서 할 수 있는 것
  - 두상 그림 고르기: 끌어서 위치를 옮기고 확대해서 원 안에 들어갈 부분을 정합니다. 100×100으로 줄여서 저장되고, 배경이 투명한 PNG는 투명하게 유지됩니다.
  - 두상 출처, 소속(이름 아래에 표시), 한마디 적기
  - 강호 이름 바꾸기 (다른 사람과 같은 이름은 불가)
- 전공록에서 다른 사람 이름을 누르면 그 사람의 두상, 소속, 한마디를 볼 수 있습니다.
- ⚠️ 이 기능을 쓰려면 `schema.sql`을 Supabase에서 **한 번 더 Run** 해야 합니다(두상 저장 칸이 새로 생김).

### 밝은 화면
- 오른쪽 위 **☀ / ☾** 버튼으로 밝은 화면(한지 느낌)과 어두운 화면을 바꿉니다. 처음 접속할 때는 기기 설정을 따르고, 고른 화면은 기억됩니다.

## 내용 바꾸기 (data.js)

GitHub에서 `data.js` → 연필 아이콘으로 바로 고칠 수 있습니다. 고친 뒤 Commit 하면 1~2분 뒤 반영됩니다.

- **하루 행동력**: `dailyAP: 50` 의 숫자
- **화면에 보이는 지도 칸 수**: `VIEW = 5` (홀수로. 7이나 9로 바꾸면 더 넓게 보입니다)
- **맵 모양**: `MAP` 의 글자 21줄(한 줄에 21글자). `C`가 기지, `E`가 야영지, `X`가 탑, 나머지 글자는 아래 `TILES`와 연결됩니다.
  지도를 크게 바꿨다면 `MAP_VERSION` 숫자를 1 올리세요. 모두의 위치가 기지로 돌아가고 밝힌 땅이 초기화됩니다(행낭, 경지, 공적은 그대로).
- **일일 임무**: 맨 아래 `QUESTS` 목록. 아직 가 보지 못한 지형·적은 일일 임무로 나오지 않습니다.
- **지형 묘사, 사건 문구**: `TILES` 안의 `desc`, `text` 따옴표 안 문장
- **새 재료/요리/장비**: `ITEMS` 에 추가하고 `RECIPES` 에 재료를 적으면 공방에 나타납니다
- **몬스터 세기**: `MONSTERS` 의 `hp`(체력) `atk`(공격) `def`(방어) `spd`(신법)

⚠️ 쉼표(`,`)와 따옴표(`"`)를 지우면 게임이 안 켜집니다. 고친 뒤 게임이 하얗게 나오면 방금 고친 줄의 쉼표와 따옴표부터 확인하세요.

## 알아둘 점 / 문제 해결

**Supabase 무료 프로젝트는 7일 동안 아무도 접속하지 않으면 일시정지됩니다.**
일시정지되면 Supabase 대시보드에서 프로젝트를 열고 **Restore** 를 누르면 다시 켜집니다. 기록은 사라지지 않습니다.

**저장 방식에 대해**
이 게임은 캐릭터 상태를 각자의 브라우저가 계산해서 저장합니다. 그래서 개발자 도구를 다룰 줄 아는 사람은 자기 수치를 조작할 수 있습니다. 지인 커뮤니티에선 보통 문제가 되지 않지만, 공적 경쟁이 치열해질 것 같다면 말해주세요. 서버 쪽 검증을 추가하는 방법이 있습니다.

| 증상 | 해결 |
|---|---|
| 가입 시 "이메일 형식 오류" | `config.js`의 `ID_EMAIL_DOMAIN` 을 다른 값(예: `mycommu.kr`)으로 바꾸기. **커뮤 시작 전에** 정해야 합니다. 바꾸면 기존 계정으로 로그인이 안 됩니다. |
| 가입 시 "이메일 확인이 켜져 있습니다" | 3단계 4번 다시 확인 |
| 고친 내용이 반영 안 됨 | 1~2분 기다린 뒤 강력 새로고침 |
| "기록 저장 실패" 알림 | Supabase 프로젝트가 일시정지되었는지 확인, `schema.sql` 을 다시 Run |
| 교환·공동 임무에서 "relation ... does not exist" 오류 | `schema.sql` 을 SQL Editor에서 다시 Run (이미 실행했던 사람도 새 표를 만들려면 한 번 더 필요) |
| 화면이 하얗게만 나옴 | 방금 고친 `data.js`/`config.js` 의 쉼표, 따옴표 확인 |
